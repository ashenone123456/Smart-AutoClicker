# Klick'r 快捷安全版使用指南

这个版本面向“识别到指定图片后再点击”的通用手机自动化，不绑定任何特定应用。

## 第一版已经优化的内容

- 新建屏幕事件默认使用 **OR**：添加多张候选图后，任意一张出现即可触发。
- 新建屏幕事件默认开启 **500 ms 冷却**。
- 开启冷却的事件需要连续两帧识别成功才会执行，短暂误识别不会立刻点击。
- 新建屏幕事件中的点击动作默认选择 **点击检测到的条件**，并支持以目标中心为基准设置 X/Y 偏移。
- 零冷却事件保持原有单帧速度，便于需要极限响应的旧场景继续使用。
- 调试版使用独立应用 ID，可与正式版同时安装，桌面名称为“**Klick'r 快捷安全版**”。

## 最省事的配置流程

1. 新建“智能场景”。
2. 每一个页面步骤建立一个屏幕事件，例如“入口”“选择场次”“选择票档”“确定”。
3. 在事件中添加一张或多张候选图片，只框选稳定、清晰且有区分度的按钮内容。
4. 保持条件组合为 OR；如果必须同时满足多个条件，再手动改为 AND。
5. 添加点击动作，保持“点击检测到的条件”，需要点击图片旁边时再设置相对偏移；如果必须点固定位置，可切换为“用户选择的位置”。
6. “按压时长”控制一次点击按住多久，“事件冷却”控制同一事件再次触发的间隔；需要动作之间固定等待时，插入“暂停”动作。
7. 先使用调试/试运行确认识别区域和点击位置，再开始正式运行。

多步骤流程不要把所有页面图片放进同一个事件。每个页面单独建事件，页面跳转后由下一个事件接管，稳定性更高。

## 快捷使用与备份

- 在系统快捷设置中添加 Klick'r 磁贴，可从通知栏快速启动场景。
- 运行时保留悬浮停止按钮；出现登录、验证码、授权、安装或支付页面时立即停止。
- 使用场景列表中的导出/导入功能备份全部图片和动作配置。
- 建议给场景写清楚应用名和用途，例如“应用 A - 预约流程”，方便一键切换。

## 荣耀 90 Pro 后台设置

MagicOS 不同版本的菜单名称可能略有差异，可直接在系统设置顶部搜索对应项目。

1. 打开“设置 → 应用 → 应用启动管理”。
2. 找到“**Klick'r 快捷安全版**”，关闭自动管理。
3. 打开“允许自启动”“允许关联启动”“允许后台活动”。
4. 在设置中搜索“电池优化”，切换到“所有应用”，找到本应用并设为“不允许优化”或“忽略电池优化”。
5. 允许悬浮窗和无障碍服务；运行时不要开启系统超级省电模式。

## 安全边界

这个应用只适合你有权控制的设备和普通重复操作。不要让自动化填写验证码、密码或支付信息，也不要绕过其他应用的访问控制。建议始终设置最大运行时间或最大执行次数，并在离开手机前停止场景。
